# Vishwakarma Wood Art & CNC Work

Static multi-page website for a custom furniture and CNC work business. The project is built with plain HTML, CSS, and JavaScript and is ready for phone and desktop layouts.

## Pages
- `index.html`
- `about.html`
- `services.html`
- `products.html`
- `contact.html`

## Main edit points
- Update business content in `assets/js/site-data.js`
- Adjust design styles in `assets/css/`
- Replace placeholder imagery in `assets/img/`

## Shared content file
`assets/js/site-data.js` controls the main repeated business data:
- brand details
- contact information
- services
- product categories and cards
- testimonials
- FAQ

## How to open
Open `index.html` in a browser, or serve the folder with any simple static file server.

## Before launch
- Replace placeholder phone, WhatsApp, email, address, and map values
- Replace placeholder product cards with real project photos if available
- Review page copy for final business language and location details
- Update social links if the business uses Instagram or Facebook

## Project notes
- The site is mobile-first and includes a collapsible navigation menu.
- Product filters are handled client-side with JavaScript.
- The current `images/logo.png` file is preserved, and a copy is used from `assets/img/brand/logo.png`.
